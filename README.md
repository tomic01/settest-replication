# SetTest replication package

Includes the SetTest suite, recorded agent and human results,
analysis scripts, and prepared HTML reports.

## Download and use

1. Open this repository's Releases section.
2. Download replication_package.zip from the release assets.
3. Extract the complete archive.
4. Open replication_package/index.html to browse the results.
5. Follow the included README.md to install dependencies,
   reproduce analyses, or run the SetTest suite.

Download the named replication_package.zip asset.

Scout and agent implementations are not included.
